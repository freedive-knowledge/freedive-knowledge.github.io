    Description

    Compétence du cursus Initiateur-Entraîneur (MFA IE, §9.1.2). Nœud créé à la promotion du lot 2026-09-24-mfa-ie ; contenu à développer.

    Exemple de programmation annuelle (livret Apnée Attitude, p.25)

    Période Type Nage Apnée
    sept.–déc. PPG 80 % 20 %
    janv.–fév. hypercapnique 20 % 80 %
    mars–avr. mixte 50 % 50 %
    mai–juin hypoxique 20 % 80 %

    Proposition de club, plausible.

    Organisation d'une saison (supports IE CODEP 91)

    Étapes de l'entraîneur (Apnée Attitude — Notions d'entrainement (IE, V.1.2024), v.5) : définir un objectif, identifier les capacités requises, organiser une progression, construire les séances, puis mesurer la progression et remédier.

    Trois échelles de temps (v.9) : la saison pour l'objectif de niveau, le trimestre comme jalon, et des cycles de séances thématiques. Règle : 1 séance = 1 objectif avec 1 axe de travail. Les efforts se répartissent entre PPG (capacités de base, plutôt physiques), PPO (orientée vers l'objectif, plutôt technique) et PPS (spécifique à une performance).

    Exemple de progression annuelle en 3 cycles (Apnée Attitude — Construire une séance d'entrainement (IE, V.1.2023), v.10) : PPG / hypercapnie (septembre-octobre), hypercapnie / hypoxie (novembre-février), hypoxie (février-juin).

    Divergence entre les deux supports sur les axes par niveau. Boulant (v.16) : matériel puis technique pour les débutants, technique puis physiologie pour les intermédiaires, physiologie puis mental pour les confirmés. Segui (v.4) : matériel et technique pour les débutants, technique et psychologique pour les intermédiaires, psychologique et physiologique pour les confirmés, physiologique pour les experts.
