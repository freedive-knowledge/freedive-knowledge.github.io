## Description

Une apnée dynamique demande l'exécution coordonnée de plusieurs actions ([[apnee-attitude-notions-entrainement-2024]], v.14) :

concentration → prise d'air → immersion → propulsion → virage → relâchement → résistance → sortie → ventilation.

Chaque action se décompose à son tour : la propulsion combine palmage, position et lestage ; la prise d'air et l'immersion doivent être intimement coordonnées.

Pour l'IE, c'est une « capacité fondamentale » : savoir quoi enseigner, quoi observer et comment y remédier (v.21).
