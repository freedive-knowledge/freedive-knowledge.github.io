## Description

Sinus frontaux, maxillaires, ethmoïdaux, sphénoïdaux. Une sinusite (muqueuse
enflammée, excès de mucus) bloque l'équilibrage (compensation v.8-9 ;
physiopathologie v.8-9). Le mucus est un frein ponctuel : se moucher avant
chaque descente ; les pathologies récurrentes relèvent du médecin
(compensation v.26).

Mahé (p.13) : l’ostium conditionne l’équilibre ; congestion (allergie, infection) qui l’obstrue. À la descente, douleur dès les premiers mètres obligeant à remonter ; à la remontée, l’air piégé se dilate : douleur vive, épistaxis, parfois syncopale. Prévention : ne pas plonger enrhumé, dépister les antécédents rhinosinusiens à la visite d’aptitude.
