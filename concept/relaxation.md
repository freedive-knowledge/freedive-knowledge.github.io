## Description

Réduction volontaire du tonus musculaire et de l'activation neurovégétative.
Diminue la consommation d'oxygène de base et retarde l'installation de
l'inconfort.

## Dans le support IE CODEP 91

Exercice type pour travailler le relâchement : « sortir à la première contraction » ([[apnee-attitude-notions-entrainement-2024]], v.25). Le relâchement musculaire pendant l'apnée porte sur la langue, le cou, les épaules et le diaphragme (v.32).
