## Description

Accessible sans prérequis ni licence (ATP). Repères : statique 1mn, dynamique 25m. Validé par un IE1 ou un E2 scaphandre. L'expérience acquise est prise en compte si le pratiquant s'engage ensuite dans le cursus certifiant. Ce n'est pas un brevet : classe `cursus` retenue faute de mieux.
